# 📈 S&P 500 Real-Time Monitor

[![DEMO LIVE TRACKER](https://img.shields.io/badge/DEMO-LIVE_TRACKER-brightgreen?style=for-the-badge&logo=github)](https://caspian1988.github.io/S-P500-real-time-monitor/)
[![Status](https://img.shields.io/badge/Status-Active-success?style=for-the-badge)]()
[![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)]()

A sleek, lightweight web application designed to track and monitor S&P 500 market data in real time. Built for speed, clarity, and zero-bloat tracking without relying on heavy third-party tracking cookies or cumbersome interfaces.

---

## ✨ Features

* **Real-Time Data Tracking:** Monitors index movements and pricing updates efficiently.
* **Clean Dashboard Interface:** High-contrast, modern UI optimized for quick visual scanning at a glance.
* **Lightweight & Fast:** Pure vanilla web technologies with zero heavy frameworks or external bloat.
* **Mobile-Responsive:** Works seamlessly across desktop workstations and mobile devices.

---

## 🚀 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Data Handling:** Asynchronous fetch requests / API integration
* **Hosting:** GitHub Pages
